# Kemtit — Planner prototype

ต้นแบบสำหรับทบทวน Product / UX วันที่ 22 กันยายน 2026 ใช้ข้อมูลตัวอย่างที่สร้างเพื่อสาธิต ไม่เชื่อมบัญชีผู้ใช้ ฐานข้อมูล Calendar หรือ LINE จริง

## เปิดดู

เปิด `index.html` ใน browser ได้โดยตรง หรือจาก project root รัน:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs/prototypes/planner-vnext
```

จากนั้นเปิด `http://127.0.0.1:4173` ข้อมูลทดลองเก็บเฉพาะใน browser ของต้นแบบ ผู้ใช้ใหม่เริ่มที่ช่องบันทึกงานแรก ส่วน “ลองดูตัวอย่าง” / “รีเซ็ตข้อมูลทดลอง” โหลดสถานการณ์สาธิต กด “ลองเริ่มใช้ครั้งแรก” ในหน้า Today ของโหมดตัวอย่างเพื่อทดสอบการเริ่มใหม่

การสลับโหมดเริ่มชุดข้อมูลทดลองใหม่ จึงเหมาะกับการลอง workflow ด้วยข้อความตัวอย่าง ไม่ใช่พื้นที่เก็บงานจริงถาวร

## เส้นทางที่ควรลอง

1. **ครั้งแรกมีที่เริ่ม:** ช่องบันทึกใน Today → พิมพ์งานของตน → “บันทึกวันนี้” → เห็นงานและทำต่อได้
2. **จดแล้วค่อยตัดสินใจ:** Quick Capture → เก็บ Inbox → เลือกงานสำหรับวันนี้
3. **จัดวันให้ทำไหว:** Today → ตรวจเวลาประชุมและพัก → ตรวจข้อเสนองานสำคัญ → ยืนยันแผน
4. **เมื่อมีงานแทรก:** ปรับแผน → ดูสิ่งที่จะย้ายและกำหนดส่ง → ยืนยัน → ย้อนกลับ
5. **เชื่อมงานกับเป้าหมาย:** Goals → รายละเอียดเป้าหมาย → งานถัดไป โดยแยกความสำเร็จของงานออกจากผลลัพธ์ที่วัดจริง
6. **ทบทวนแล้วเดินต่อ:** Review → ตัดสินใจงานค้าง → เลือกสิ่งที่จะทำในสัปดาห์หน้า → Planner
7. **เข้าใช้ได้ง่าย:** Login → “เข้าสู่ระบบด้วย Google” → จำลองสำเร็จหรือยกเลิก; อีเมลเป็นทางเลือกเดิม การทดลองไม่เชื่อมบัญชีจริง

หน้า Finance, Routine, Projects และ Sales ใช้แสดงบริบทเสริม ผู้ใช้ไม่จำเป็นต้องตั้งค่าทุกด้านก่อนเริ่มวางแผนวันแรก เมนู “ดูทุกหน้า” / More ช่วยสำรวจหน้าทั้งหมด

## ขอบเขต

- เป็น UI และการจำลอง interaction สำหรับประเมินแนวคิด ไม่ใช่ production implementation
- ไม่ส่งข้อความ ไม่ทำ OAuth ไม่บันทึกธุรกรรมหรือชำระเงินจริง
- ข้อมูลสถิติและวันที่ในต้นแบบเป็นข้อมูลตัวอย่าง ไม่ใช่ผลวัดจากผู้ใช้ Kemtit
- ความสามารถที่เสนอ เช่นการจัดเวลาตามภาระจริงและการปรับแผน ต้องพัฒนาและทดสอบ backend ตามแผนก่อนเปิดใช้จริง
- ใช้ design tokens ลาเวนเดอร์/พีชและฟอนต์ IBM Plex Sans Thai ไฟล์ต้นฉบับจาก Google Fonts แบบ self-host พร้อม [OFL ฉบับเต็ม](fonts/OFL.txt) และ [แหล่งที่มา/แฮช](fonts/source-provenance.md)
- ไอคอนใช้ Lucide พร้อม ISC/MIT notice; ปุ่ม Google ใช้ภาพปุ่มทางการที่มีเงื่อนไขเครื่องหมายแยกจากใบอนุญาตไอคอน ดู [รายการแหล่งที่มา](licenses/README.md)
