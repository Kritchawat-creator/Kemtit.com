# Kemtit — ต้นแบบแผนชีวิตสำหรับพิจารณา

วันที่ 9 ตุลาคม 2026 · ระยะ 0 · ยังไม่ได้รับการอนุมัติต้นแบบ

ต้นแบบโต้ตอบได้สำหรับแผน [Life Planning UX](../../plans/2026-10-09-life-planning-ux-delivery-plan.md) ออกแบบโครงหน้า ข้อความ และองค์ประกอบขึ้นเอง ไม่ใช้ภาพอ้างอิงเป็น asset หรือถอดแบบหน้าเหล่านั้น

## เปิดใช้งาน

จาก root โครงการ:

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory docs/prototypes
```

เปิด <http://127.0.0.1:8767/life-planner-review/> ไม่ต้องล็อกอิน

ใช้เฉพาะข้อมูลจำลอง เก็บใน localStorage ชื่อ `kemtit-life-planner-review-v1` แยกตามเบราว์เซอร์และ origin ไม่เรียก API หรือเชื่อมบัญชีจริง ภาพที่เลือกอ่านด้วย FileReader และเก็บในเบราว์เซอร์นี้เท่านั้น ไม่ใช่การอัปโหลดไปเซิร์ฟเวอร์ อย่าใช้ข้อมูลส่วนตัวสำหรับทดสอบ

ชุดข้อมูล “ทั่วไป / ว่าง / รายการมาก” อยู่ใน “ข้อมูลทดสอบ” การเปลี่ยนชุดจะทดแทนข้อมูล **ของต้นแบบ** รวมรูป/กลุ่ม/การทบทวน และย้อนกลับได้หนึ่งครั้ง การย้อนกลับไม่ได้อยู่ข้าม reload

## เส้นทางที่ลองได้

1. **วันนี้:** เลือกสิ่งสำคัญไม่เกิน 3 งาน ดูเวลาที่จัดไว้ เพิ่มการ์ด และเปิดรายละเอียด
2. **ภาพรวมชีวิต:** เป้าหมาย → ดูเฉพาะงานที่เชื่อม → กลับรายการทั้งหมด ตัวเลขคือจำนวนงานที่เชื่อม ไม่ใช่คะแนนชีวิต
3. **ปฏิทิน:** ตารางสัปดาห์บน desktop และวันเดียวบนหน้าจอแคบ สลับรายการเรียงเวลาได้
4. **ตัวช่วย:** ความตั้งใจ → ก้าวแรก → ตรวจสิ่งที่จะสร้างก่อนยืนยัน; ย้อนขั้นรักษาข้อความ
5. **ทบทวน:** 3 คำถาม บันทึกแล้วกลับมาอ่านได้ สรุปจำนวนงานอ้างอิงชุดข้อมูลจำลองทั้งหมด ยังไม่กรองช่วงสัปดาห์จริง

## การ์ด / เวลา / กลุ่ม / รูป

- ลากจุดจับลงช่องเวลา เปลี่ยนวันเวลาในการ์ดเดิม; ลากบล็อกในปฏิทินเพื่อย้าย เวลา snap ทีละ 15 นาที รักษาระยะเวลา
- ต้นแบบจำกัดช่วง 08:00–20:00 และปฏิเสธเวลาทับซ้อน การกด “จัดเวลา” ใช้แทนการลากได้
- ลากค้างบนการ์ดอื่นอย่างน้อย 450 ms เพื่อสร้างกลุ่ม หรือปล่อยบนกลุ่มที่มีอยู่เพื่อเพิ่มสมาชิก ใช้ปุ่ม “จัดกลุ่ม” เป็นทางเลือก
- กลุ่มระดับเดียว สมาชิกยังเป็นงานเดิม รักษาตารางเวลา; เปลี่ยนชื่อ นำสมาชิกออก และยุบกลุ่มได้ ไม่รองรับลากทั้งกลุ่มไปปฏิทิน
- การลากสัมผัสใช้กดค้าง 220 ms ที่จุดจับ; มี pointer cancel / Escape / resize cancellation แต่ยังไม่ได้ตรวจนิ้วหรือ Pencil บนอุปกรณ์จริง
- รูป JPEG/PNG/WebP ไม่เกิน 5 รูปต่อการ์ดและ 3 MB ต่อชุดที่เลือก ภาพแรกตามลำดับที่เลือกเป็น cover; เมื่อนำออกใช้ภาพถัดไป ชื่องานยังแสดงเสมอ
- รายการย่อยในตัวอย่างเป็น checklist ของงาน ไม่รีเซ็ตตามวันหรือ occurrence
- จำลองบันทึกล้มเหลว และ Undo แบบหนึ่งขั้นได้ ข้อมูลบันทึก local ไม่ใช่สัญญา server transaction/version/idempotency

## ขอบเขตและสิ่งที่ยังต้องทำ

นี่คือ mockup ชุดแรกสำหรับพิจารณา ไม่ใช่แอปที่พร้อมปล่อย ไม่เปลี่ยน `src/`, database, auth, routes หรือ integration เดิม ยังไม่มี calendar เดือน/ปี, recurring occurrences, deadline, timezone/DST, actual focus tracking, habits, export, TH/EN switching หรือ concurrent writes

ต้องตรวจการลากค้างสร้างกลุ่มด้วยผู้ใช้, การลากด้วยนิ้ว/Pencil บนโทรศัพท์/iPad จริง, keyboard/focus ครบโฟลว์, zoom 200%, accessibility และทดสอบผู้ใช้ตัวแทนตามแผนก่อนปิดระยะ 0 รายละเอียดหลักฐานอยู่ใน [QA.md](QA.md)

## ที่มาของทรัพยากร

HTML/CSS/JS และข้อความ UI สร้างสำหรับ Kemtit ไม่มี artwork จากภาพอ้างอิง ใช้อักขระมาตรฐานสำหรับเครื่องหมาย ไม่ใช้ชุดไอคอนภายนอก

ฟอนต์อ้างอิงไฟล์ IBM Plex Sans Thai เดิมของโครงการโดยไม่คัดลอกเพิ่ม: [ที่มาและ hash](../planner-vnext/fonts/source-provenance.md), [SIL Open Font License](../planner-vnext/fonts/OFL.txt) ภาพ cover ที่ใช้ตรวจเป็น PNG สีล้วนที่สร้างเองสำหรับ QA
