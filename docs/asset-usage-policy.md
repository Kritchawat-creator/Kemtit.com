# การใช้ฟอนต์ ภาพ ไอคอน และเครื่องหมายใน Kemtit

กำหนดตามคำขอผู้ใช้วันที่ 22 กันยายน 2026

ใช้คำว่า **มีสิทธิ์ใช้เชิงพาณิชย์ตามเงื่อนไข** แทนการรับรองว่า “ไม่มีลิขสิทธิ์” งานที่ใช้ใบอนุญาตแบบ open source ยังมีเจ้าของลิขสิทธิ์ และใบอนุญาตซอฟต์แวร์ไม่ได้ให้สิทธิ์เครื่องหมายการค้าโดยอัตโนมัติ

## ก่อนเพิ่มหรือเปลี่ยน asset ที่แจกไปกับระบบ

1. ระบุเจ้าของ แหล่งต้นฉบับ รุ่น/commit ไฟล์ที่ใช้ และ SHA-256
2. เก็บข้อความใบอนุญาตฉบับเต็มและ copyright notice; ตรวจว่าอนุญาตการใช้เชิงพาณิชย์และการแจกไฟล์ในรูปแบบที่จะใช้งาน
3. บันทึกว่าดัดแปลงหรือไม่ และทำตามเงื่อนไขเรื่องชื่อสงวน/attribution/การแจกต่อ ไม่ลบ notice เพื่อทำให้ดูเหมือนเป็นงานของเรา
4. ถ้าพิสูจน์สิทธิ์ไม่ได้ ให้เปลี่ยนเป็น asset ที่มีหลักฐานหรือเว้นออกจากชุดเผยแพร่จนกว่าจะตรวจได้ การพบรูปบนเว็บหรือคำว่า “free” อย่างเดียวไม่พอ
5. ตรวจเครื่องหมายแยกจาก copyright: ใช้เครื่องหมายของผู้ให้บริการเฉพาะบริบทที่อนุญาต เช่นปุ่มเข้าระบบ ตามคู่มือทางการ ไม่ใช้เป็นแบรนด์ Kemtit หรือสื่อว่ามีการรับรอง/เป็นพาร์ตเนอร์
6. เมื่ออัปเดต package/asset ให้เทียบ license และ provenance ใหม่ เก็บ notice ให้ตรงกับรุ่นที่แจก

## แนวทางที่เลือก

- ฟอนต์หลัก: IBM Plex Sans Thai จาก Google Fonts ใบอนุญาต SIL OFL 1.1 ใช้ไฟล์ต้นฉบับและ self-host เพื่อให้มีหลักฐานไฟล์และไม่ต้องร้องขอฟอนต์จากภายนอกตอนผู้ใช้เปิดหน้า
- ไอคอนทั่วไป: Lucide รุ่นที่ติดตั้งในโครงการ เก็บทั้ง ISC และ MIT notice สำหรับส่วนที่สืบทอดจาก Feather ไม่อ้างสิทธิ์เฉพาะในรูปไอคอนทั่วไป
- ปุ่ม Google: ใช้ asset ปุ่มที่ Google จัดให้ตาม branding guidelines และติดตามแยกเป็น branded asset ไม่ใส่ไว้ในหมวด OFL/MIT หรือเรียกว่า trademark-free
- ภาพประกอบ/กราฟที่เขียนขึ้นในโครงการ: เก็บ source และที่มาของงาน การเห็น source ไม่ใช่หลักฐานว่าได้ตรวจความคล้ายกับงานหรือเครื่องหมายทั้งหมดในตลาดแล้ว
- รูปจากผู้ใช้/ลูกค้า: อยู่นอกการรับรองสิทธิ์ของ static asset inventory ต้องพิจารณาสิทธิ์ของผู้ส่งและบริบทการใช้งานแยกกัน

## สิ่งที่ยังไม่ถือว่าผ่าน

ชื่อและโลโก้ Kemtit ยังไม่มีผลตรวจเครื่องหมายการค้าตามประเทศและกลุ่มสินค้า/บริการในงานรอบนี้ ต้องมีหลักฐานก่อนกล่าวว่าแบรนด์ผ่าน trademark clearance การตรวจ asset และใบอนุญาตไม่ทดแทนขั้นตอนนี้

รายการ notices ของ UI เป็นขอบเขตที่ตรวจได้ในรอบนี้ ไม่ใช่รายงานใบอนุญาตของ dependency ทางอ้อมทั้งหมด และไม่ใช่ใบรับรองทางกฎหมาย
